# C1 固件结构（当前实现）

平台：STM32F407ZGT6、HAL、FreeRTOS。Keil 和 GCC 共用 `C1_Keil/Core` 下的源码。

## 1. 先看整体流程

```text
树莓派速度命令
      │ USART3
      ▼
逐字节接收中断 → 协议解析 → 接收队列
                              │
                              ▼
                     Control 任务
               命令 / 超时 / 安全状态
                     │       ▲
       目标斜坡 → PI → PWM    │ 编码器测速
                     ▼       │
                 BTS7960 → 电机

状态帧/ACK 队列 → Telemetry 任务 → USART3
```

读控制代码时可以先记住一句话：**每个轮子用目标速度减去编码器实测速度得到误差，PI 把误差换成 PWM；目标速度先经过加速度斜坡。**

## 2. 任务和中断

| 部分 | 触发方式 | 作用 |
| --- | --- | --- |
| USART3 接收中断 | 每收 1 字节 | 投喂协议解析器；完整且 CRC 正确的帧复制进接收队列。中断不执行电机控制。 |
| TIM7 中断 | 1 kHz | 递增毫秒计数并唤醒 Control 任务。 |
| `Task_Control` | TIM7 通知 | 取命令、检查通信超时；每经过至少 20 ms 同时更新编码器并执行一次速度环；刷新 IWDG。 |
| `Task_Telemetry` | 发送队列 | 唯一的 UART 发送者，发送状态帧和 ACK。 |

串口和 TIM7 都在调度器启动后由 Control 任务开启，避免调度器尚未运行时从中断调用 FreeRTOS 队列/通知接口。状态每 50 ms 上报一次，即 20 Hz。

## 3. 速度闭环

左右轮各自运行同一套计算：

```text
目标斜坡：r ← 向命令目标移动，单周期最多变化 ACC_MAX_MMPS2 × dt
速度误差：e = r - 编码器测得速度
积分项：  I ← 限幅(I + Ki × e × dt)
控制输出：PWM = 限幅(Kp × e + I)
```

- 采样周期目标是 20 ms（50 Hz）。若任务偶尔晚醒，代码把实际经过的毫秒数传给测速和积分计算。
- `Kp`、`Ki` 的默认值只是启动参数，不是实车整定结果。编码器比例确认后，先架空单轮低速调试，再调整它们。
- `PWM_DEADZONE_PERMILLE` 默认 0。只有实测得出电机无法启动的占空比区间后才填入死区值。
- 停车和反向都经过目标斜坡。速度反馈仍显示车轮在转时，PI 可能给出相反方向的控制力来减速。

## 4. 状态和安全行为

| 状态 | 含义 |
| --- | --- |
| `IDLE` | 输出 PWM 为零，软件输出禁止。 |
| `RUN` | 跟踪左右轮速度目标。 |
| `STOPPING` | 目标按斜坡降到零；实测速度足够低后转入 IDLE。 |
| `FAULT` | 锁定输出，必须发送清除命令并满足低速条件后恢复。 |

- 500 ms 没有合法帧且车辆正在运行/停车时，进入 STOPPING 并报告通信超时。
- 超过 1 s 仍未恢复，会进入锁定故障。收到新速度命令可恢复 500 ms 软停状态；锁定后需发送 `CMD_CLEAR_ESTOP`。
- `CMD_ESTOP` 会立即把 PWM 清零并禁止软件输出。此动作依赖 MCU 和固件正常运行，**不能替代切断电机动力的硬件急停**。
- 堵转检测默认关闭，因为每轮实际计数尚未标定。可在 `config.h` 开启编码器静止检测；它仍不等同于电流保护。
- 工程没有真实母线电流和电池电压 ADC。过流估算、欠压阈值不参与控制；状态帧电压用 `0xFFFF` 表示未知。
- IWDG 由 Control 任务定期刷新；若控制任务不再运行，看门狗会复位 MCU。

## 5. 主要文件

| 文件 | 用途 |
| --- | --- |
| `C1_Keil/Core/Src/main.c` | 时钟、USART3、TIM2/3/7/8、看门狗初始化；接收回调。 |
| `C1_Keil/Core/Src/app_tasks.c` | 命令处理、安全状态、目标斜坡、PI 和 UART 发送队列。 |
| `C1_Keil/Core/Src/encoder.c` | 定时器计数转换成 mm/s 和累计 mm。 |
| `C1_Keil/Core/Src/motor.c` | 正负占空比转换成 BTS7960 的 RPWM/LPWM。 |
| `C1_Keil/Core/Src/protocol.c` | 帧解析、CRC16、小端数据打包。 |
| `C1_Keil/Core/Inc/config.h` | 编码器每轮计数、轮径、方向、控制周期和 PI 参数。 |

## 6. 上车前要确认的硬件值

1. 用户提供的编码器资料标注 16 PPR，但没有说明是电机轴还是减速箱输出轴。配置暂按 `16 × 4 × 56 = 3584` 个计数/轮转。逐个轮子手动转一圈，以实际计数替换 `ENCODER_COUNTS_PER_WHEEL_REV`。
2. `ENCODER_LEFT_SIGN`、`ENCODER_RIGHT_SIGN` 要让机器人前进时左右速度都为正；必要时设为 `-1`。电机方向可用 `MOTOR_LEFT_SIGN`、`MOTOR_RIGHT_SIGN` 单独修正。
3. PB4/PB5 还连接板载 W25Q128；PB0/PB1 与触摸屏信号复用。用作电机 PWM 时不要同时启用对应板载外设，Flash 片选 PG8 必须保持未选中。
4. PA15/PB3 与 JTAG 复用，调试请使用 SWD。PC6/PC7 同时是 USART6，使用右轮编码器时不能再用 USART6。
5. BTS7960 EN 默认不由 PA5/PF11 驱动；模块按资料接法把 EN 拉高。PA5/PF11 与触摸屏复用。PA0 是 UART4_TX，默认不作为电源开关。

改动前先读 `config.h`，每个参数应带明确单位和已知来源。未接入 ADC 或外部安全电路的保护，不能只凭软件变量宣称已经实现。
