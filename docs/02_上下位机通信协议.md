# C1 上下位机通信协议

物理层：USART3，PB10=TX、PB11=RX，TTL 3.3 V，共地；默认 115200、8N1。

## 1. 帧格式

| 字段 | 长度 | 说明 |
| --- | ---: | --- |
| SOF | 2 B | 固定 `AA 55` |
| LEN | 1 B | `SEQ + CMD + DATA` 的字节数，不含帧头、LEN 自身和 CRC |
| SEQ | 1 B | 序号，0～255 循环 |
| CMD | 1 B | 命令码 |
| DATA | 0～32 B | 命令数据，小端序 |
| CRC | 2 B | CRC16-Modbus，覆盖 LEN 到 DATA，小端存放 |

接收中断每次收 1 字节。只有长度和 CRC 均正确的帧才进入命令队列。

## 2. 上位机命令

| CMD | 名称 | DATA | 下位机行为 |
| --- | --- | --- | --- |
| `0x01` | 设置左右轮速度 | `i16 left_mmps, i16 right_mmps` | 每轮限幅到 ±1000 mm/s，进入 RUN；目标经过加速度斜坡。成功回 ACK。 |
| `0x02` | 软停 | 无 | 目标按斜坡降为 0，轮速足够低后进入 IDLE。成功回 ACK。 |
| `0x03` | 急停 | 无 | PWM 立即清零、锁定输出。成功回 ACK。 |
| `0x04` | 清除锁定 | 无 | 左右实测速度均不超过 20 mm/s 时清除锁定，否则回错误码 4。 |
| `0x05` | 里程清零 | 无 | 左右累计里程清零。 |
| `0x06` | 设置 PI 参数 | `i16 kp_x1000, i16 ki_x1000` | `Kp` 范围 0～2，`Ki` 范围 0～20（每秒）；不写入 Flash。 |
| `0x07` | 心跳 | 无 | 续期通信看门超时，不回 ACK。 |
| `0x11` | 查询状态 | 无 | 立即排入一帧 `0x10` 状态。 |

`0x01` 速度单位是 mm/s，负值表示倒退。若急停已锁定，设置速度会回错误码 3，不会启动电机。

## 3. 下位机帧

### 状态帧 `0x10`

数据域固定 17 字节：

| 偏移 | 类型 | 含义 |
| ---: | --- | --- |
| 0 | `u8` | 状态：0 INIT、1 IDLE、2 RUN、3 FAULT、4 STOPPING |
| 1 | `u8` | 故障码 |
| 2 | `u16` | 母线电压 mV；`0xFFFF` 表示没有真实 ADC 采样、未知 |
| 4 | `i16` | 左轮速度 mm/s |
| 6 | `i16` | 右轮速度 mm/s |
| 8 | `i32` | 左轮累计里程 mm |
| 12 | `i32` | 右轮累计里程 mm |
| 16 | `u8` | 状态位 flags |

固件每 50 ms 上报一次；收到查询时也会排入状态帧。串口发送由单一 Telemetry 任务完成。

### ACK/NACK `0x7F`

数据域为 `u8 acknowledged_cmd, u8 result`：`0` 成功、`1` 未知命令、`2` 数据长度或 PI 参数错误、`3` 输出被锁定、`4` 车轮还未停稳。

### flags

| 位 | 含义 |
| --- | --- |
| bit0 | 软件控制的电源开关输出为 ON；默认硬件没有此控制，因而为 0 |
| bit1 | 固件允许输出 PWM；不代表硬件急停链路正常 |
| bit2 | 急停或通信丢失故障处于锁定状态 |
| bit3～7 | 保留，置 0 |

## 4. 状态和保护

- IDLE：PWM 为零、软件输出关闭。
- RUN：闭环跟踪左右轮速度。
- STOPPING：目标按斜坡降到零，速度低于门槛后回 IDLE。
- FAULT：PWM 清零并锁定输出；满足低速条件后发送 `0x04` 才能清除。
- 正在运行/停车时 500 ms 没有合法帧，会软停并报告通信超时；超过 1 s 仍未恢复会锁定。
- `0x03` 是软件急停，不能替代独立的硬件电机电源切断开关或急停按钮。
- 当前固件没有电池电压/母线电流 ADC。过流、欠压和真实电源状态不可从状态帧获得；堵转检测默认关闭，需先校准编码器。

故障码：`0` 正常、`1` 通信超时、`2` 急停、`3` 编码器静止堵转。`4` 过流、`5` 欠压、`6` 编码器异常为协议保留值，当前实现不会产生这些诊断。

## 5. 示例帧

设置左右轮各 200 mm/s：

```text
AA 55 06 01 01 C8 00 C8 00 28 B1
```

状态帧里的电压未知时，应把 mV 字段写为 `FF FF`，不要填入估算值或固定电压。

## 6. ROS2 对应关系

- ROS2 `/cmd_vel` 经差速解算得到左右轮目标：`vL = v - ωL/2`，`vR = v + ωL/2`；其中轮距 `L` 使用 mm、`ω` 使用 rad/s、线速度使用 mm/s。
- 收到状态帧后，可用左右累计里程计算里程计。不要把未知电压 `0xFFFF` 转成真实电压发布。
