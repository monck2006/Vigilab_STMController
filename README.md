## 快速开始

**编译**

```powershell
# 方式一：Keil 打开工程后 Build（或命令行）
& "D:\keil5\UV4\UV4.exe" -b C1_Keil\Project\C1.uvprojx -o build.log

# 方式二：命令行 GCC（需要 arm-none-eabi-gcc）
cd C1_GCC
powershell -ExecutionPolicy Bypass -File build.ps1
```

**不接硬件做验证**

```powershell
python tools\verify_image.py      # 校验 HEX 与向量表
python tools\sim_logic.py         # 跑控制逻辑仿真（6 个场景）
python tools\serial_tester.py selftest   # 协议自检
```

**接上硬件后**

```powershell
python tools\serial_tester.py -p COM3 monitor   # 看 20Hz 状态上报
python tools\serial_tester.py -p COM3 speed 200 200
python tools\encoder_calib.py -p COM3 --distance 2000
```

## 一、任务范围

1. STM32 固件架构设计 —— 基于 FreeRTOS 划分任务（电机控制、通信、传感器采样、安全监控），定义任务优先级与调度策略。
2. 上下位机通信协议 —— 定义 UART 数据帧格式（帧头 / 校验 / 指令类型 / 数据字段），实现 STM32 串口收发驱动。
3. 电机驱动层开发 —— BTS7960 H 桥控制逻辑（PWM + 方向引脚），正反转、调速、急停；编码器正交解码（TIM 编码器模式）实时读取转速。

## 四、引脚分配（已对照《启明欣欣407开发板(高配版)V6.1原理图》核对）

选脚原则：**编码器是输入信号且大概率是 5V 电平，所以全部选 5V 容忍（FT）引脚**；PA0/PA1 是 ADC 脚不能吃 5V，故不用作编码器输入。

| 功能 | 引脚 | 片上资源 | 板上引出位置 |
| --- | --- | --- | --- |
| 与树莓派通信 | PB10 (TX) / PB11 (RX) | USART3 | P7 引出接口 第 7 / 5 脚（丝印 URAT3-TTL） |
| 电机 1 RPWM / LPWM | PB4 / PB5 | TIM3_CH1 / TIM3_CH2 | P7 第 29 / 28 脚 |
| 电机 2 RPWM / LPWM | PB0 / PB1 | TIM3_CH3 / TIM3_CH4 | P12 第 17 / 16 脚 |
| 编码器 1 A / B | PA15 / PB3 | TIM2_CH1 / TIM2_CH2（32 位） | P12 第 21 脚 / P7 第 27 脚 |
| 编码器 2 A / B | PC6 / PC7 | TIM8_CH1 / TIM8_CH2 | P16 排针（丝印 URAT6-TTL） |
| BTS7960 EN ×2（可选） | PA5 / PF11 | 普通 GPIO | P12 第 22 / 15 脚 |

说明：

- 两个电机共用 TIM3 的四个通道，PWM 频率天然一致、波形同步，适合差速底盘。
- 两路编码器分别用 TIM2、TIM8，互不干扰；TIM2 是 32 位计数器。
- 树莓派也可改用 USART6（PC6/PC7，P16 排针）；若用 USART1（P20），注意该网络与 MAX232 的 R1OUT 相连，会与树莓派 TX 抢线，需串 1kΩ 或不用 DB9。
- 板上 P7 / P12 多数引脚属于外挂 SRAM 与 LCD 的 FSMC 总线，本方案刻意避开了它们。
- 调试必须用 SWD，不能选 JTAG（PA15/PB3/PB4 被占用）。
- PA5 / PF11 是触摸屏引脚，不接 LCD 时可用。
